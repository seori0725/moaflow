# MoaFlow MVP · 5단계 운영자 기능 완성

학원·학부모 기능 위에 파일럿 운영 현황과 지원 업무를 관리하는 운영자 기능 완성 프로토타입입니다.

## 구현 범위

- 반 전체 완료를 기본값으로 하는 학생별 과제 수행 상태와 예외 메모
- 완료·일부 완료·미완료·미제출·면제·대체 상태
- 반·과목별 테스트 사용 주기와 반 평균 공개 설정
- 주간·월간·비정기 테스트, 결시, 재시험, 모든 응시 시도 보존
- 원장 전용 점수 수정이력
- 출결·과제·테스트·진도 원본 기반 주·월·누적 자동 통계
- 데이터 부족 시 실제 누적 집계기간 표시
- 내부 상담 메모, 보호자 공유 요약, 후속조치 분리 저장
- 여러 학원의 출결·학습·과제·테스트·코멘트 통합 타임라인
- 자녀·학원 필터와 연결 학원 수 요약
- 평가 성취도, 직전 대비, 출석률, 과제 완료율 성장 추이
- 보호자 공유 코멘트 전용 화면, 강사의 담당 학생 코멘트, 내부 메모 비노출
- 학부모·학원 답변 이력과 양쪽 새 답변 확인 상태
- 연결된 자녀·학원 알림과 개별·전체 읽음 처리
- 기간별 출결·학습 입력률과 학부모 조회율
- 학습분석·성장추이의 고유 사용자 활용률, 재방문율, 학원별 최근 사용
- 학원별 5단계 전환 현황과 최근 활동
- 파일럿 준비·운영·중지·종료 상태 관리
- 오류·문의 접수, 우선순위, 처리 상태, 답변 및 이력 관리
- 1·2단계 로그인·권한·CSV·출결·학습·보호자 연결 흐름 유지

## 실행과 데모

브라우저에서 `index.html`을 엽니다.

- 인증번호: `123456`
- 보호자 연결: `MF-4821`, 생년월일 `2012-05-18`
- 데이터는 브라우저 로컬 저장소에 자동 저장됩니다.

## 검증

`npm install` 후 `npm test`를 실행하면 기존 회귀 흐름과 운영자 파일럿·지표·오류·문의 관리를 자동 검증합니다.

## 파일럿 배포 전 필수 전환

현재 결과물은 흐름 검증용 정적 프로토타입입니다. 실제 학생·보호자 정보를 사용하는 파일럿 배포 전에는 데모 인증번호와 브라우저 로컬 저장소를 제거하고, 서버 인증·권한 검증·암호화된 데이터베이스·보관 및 삭제 정책으로 전환해야 합니다.
