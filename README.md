# MoaFlow MVP · 2단계 최소 전체 플로우

PRD v2.5, 유저플로우 v2.4, 16개 와이어프레임과 개발 순서에 맞춘 최소 전체 플로우 프로토타입입니다.

## 구현 범위

- 학원 원생 CSV 등록과 오류 행 제외
- CSV 실제 날짜 검증, 중복 제외 분리와 오류 행별 사유
- 반별 출결 일괄 입력·예외 사유·수정 이력
- 교재·진도·학습내용·과제·특이사항·다음 계획을 포함한 일별 학습기록
- 원생의 현재 반 변경, 변경일·변경자 표시와 누적 이력 보관
- 24시간 1회용 보호자 초대와 자녀 관계 확인
- 연결된 자녀의 출결·학습 통합 홈
- 운영자용 오늘 기준 CSV·입력률·연결·조회 지표
- 1단계 로그인·역할·권한·공통 데이터 구조 유지

## 실행과 데모

브라우저에서 `index.html`을 엽니다.

- 인증번호: `123456`
- 보호자 연결: `MF-4821`, 생년월일 `2012-05-18`
- 데이터는 브라우저 로컬 저장소에 자동 저장됩니다.

## 검증

`npm install` 후 `npm test`를 실행하면 핵심 역할·권한·CSV·출결·보호자 연결 흐름을 자동 검증합니다.

## 파일럿 배포 전 필수 전환

현재 결과물은 2단계 흐름 검증용 정적 프로토타입입니다. 실제 학생·보호자 정보를 사용하는 파일럿 배포 전에는 데모 인증번호와 브라우저 로컬 저장소를 제거하고, 서버 인증·권한 검증·암호화된 데이터베이스·보관 및 삭제 정책으로 전환해야 합니다.
